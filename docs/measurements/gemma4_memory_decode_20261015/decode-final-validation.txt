- 전체 플랫폼 CI, corpus PPL, TSan은 통과했다고 주장하지 않는다. TSan은 이 host에서
  runtime mapping 오류로 시작하지 못했다.

별도 메모리 변경과 결합 가능성도 읽기 전용으로 검토했다. Compact C20의 실측은
없고, compact C24는 기존 C16보다 steady memory가 증가한 기록이 있어 이번에는
적용하지 않았다. 16 TPS가 불가능하다는 결론이나 현재 값이 이론적 한계라는
주장을 하지는 않는다. 현재 검증된 수정으로는 목표에 도달하지 못했다.
