11. HTML 문서 열기 및 관리

gemma4-moe-npu-guide/index.html은 소개, 11개 섹션과 LFM2 벤치마크 부록을 개별 페이지로 제공합니다. 분류된 사이드바, 페이지별 목차, 이전/다음 링크, 본문 검색, 코드 복사, 밝은/어두운 테마를 사용할 수 있습니다. 작은 화면에서는 메뉴 버튼으로 탐색 메뉴를 여세요. 검색은 Ctrl+K, macOS에서는 Command+K로도 열 수 있습니다.

페이지의 한국어 / English 선택으로 현재 섹션과 소제목 위치를 유지한 채 언어를 바꿀 수 있습니다. 한국어 페이지는 gemma4-moe-npu-guide/ko/index.html에서 시작합니다. 검색과 메뉴도 선택한 언어를 따릅니다. 기본 영어 시작 페이지를 여는 명령은 아래와 같으며, 한국어로 바로 열려면 경로의 index.html을 ko/index.html로 바꾸세요.

탐색 구조는 XGrammar 문서의 방식을 참고했습니다. 스타일, 스크립트, 검색 색인은 모두 로컬 파일이므로 CDN이나 온라인 검색 서비스가 필요하지 않습니다.

Linux 데스크톱에서 이 문서가 있는 체크아웃을 기준으로 실행합니다.

xdg-open docs/gemma4-moe-npu-guide/index.html

HTTP로 제공하려면 가이드가 있는 체크아웃에서 다음 명령을 실행하고 터미널을 유지합니다.

python3 tools/serve_gemma4_npu_guide.py --bind 0.0.0.0 --port 8765

같은 PC에서는 http://localhost:8765/, 접근 가능한 다른 기기에서는 http://<host-ip>:8765/를 엽니다. 한국어 시작 주소는 http://localhost:8765/ko/입니다. 서버는 이 문서와 관련 리소스, Markdown 원본, 단일 페이지 보기만 제공합니다. 호스트 안에서만 접근하려면 --bind 127.0.0.1을 사용하세요. Ctrl+C로 종료하고 같은 명령으로 다시 시작할 수 있습니다. 포트가 사용 중이면 기존 가이드 서버를 종료하거나 다른 포트를 선택하세요. 페이지를 재생성한 뒤에는 브라우저를 새로고침합니다.

기존 gemma4-moe-npu-guide.html은 독립 파일로 유지됩니다. 한국어 단일 페이지 파일은 gemma4-moe-npu-guide.ko.html입니다. 전체 내용과 스타일이 한 파일에 들어 있습니다. 오프라인에서 스크린샷과 벤치마크 자료도 열려면 옆의 gemma4-moe-npu-guide/assets/ 디렉터리를 함께 유지하세요. 페이지별 사이트를 복사하려면 gemma4-moe-npu-guide/ 전체와 옆에 있는 영어·한국어 .html, .md 파일을 함께 복사하세요. 브라우저의 인쇄 → PDF로 저장은 인쇄 스타일을 사용합니다. 가이드 전체를 인쇄하려면 단일 페이지 보기를 선택하세요. 외부 참고 링크를 열려면 인터넷 연결이 필요합니다.

내용의 원본은 영어 gemma4-moe-npu-guide.md와 한국어 gemma4-moe-npu-guide.ko.md입니다. 수정 후 같은 체크아웃에서 HTML을 재생성합니다. 렌더러는 기준 PR 소스가 아닌 이번 문서 추가 작업에 포함된 도구입니다.

python3 -m venv /tmp/nntr-guide-venv
/tmp/nntr-guide-venv/bin/python -m pip install markdown-it-py==3.0.0
/tmp/nntr-guide-venv/bin/python tools/render_gemma4_npu_guide.py
/tmp/nntr-guide-venv/bin/python tools/render_gemma4_npu_guide.py --check

렌더러는 두 언어의 단일 페이지 HTML, 언어별 13개 페이지, 검색 색인을 함께 갱신합니다. 본문은 각 언어의 Markdown에서, 표현과 동작은 사이트 디렉터리의 assets/site.css와 assets/site.js에서 수정하세요. 두 원본의 제목 계층과 순서는 일치하게 유지합니다. 명령 블록을 바꿀 때는 두 언어에 함께 반영하세요. 생성된 HTML과 각 언어의 assets/search-index.js는 직접 수정하지 않습니다.

검증 범위 및 참고 자료

이 안내는 기준 PR의 스크립트, CLI 파서, 앱 설정, Quick.AI 문서 및 로컬에 있는 HexKL beta2 압축 파일 구조와 대조했습니다. 문서 작성 과정에서 SDK 신규 설치와 Android 빌드는 수행하지 않았습니다. 앱 화면을 추가할 때는 기존에 설치된 Quick.AI 2.0과 기기에 준비된 TL2 팩으로 모델 로드, 짧은 질문 1회, Metrics 표시 및 언로드를 확인했습니다. 설치된 APK의 소스 커밋은 확인하지 않았으므로, 이 캡처는 화면 사용법의 근거이며 가이드의 고정 커밋을 처음부터 빌드해 검증한 결과는 아닙니다. PR의 빌드 및 기기 검증 기록도 이 가이드 전체를 새로 실행한 결과와 구분합니다.

벤치마크는 SM-S948U에 배포된 TL2 팩으로 별도 측정했습니다. 입력 1K·2K·4K·8K마다 CLI를 3회씩 실행하고 모든 출력이 128토큰인지 확인했습니다. 런타임 라이브러리는 설치된 앱과 SHA-256이 같은지 검증했으며, 원본 로그·토큰 트레이스·설정·바이너리 해시를 결과와 함께 제공합니다.

차이가 발견되면 다음 고정 리비전의 소스를 참고하세요.

  • Android 빌드 스크립트: 지원 옵션, 필수 조건, 산출물, 배포.
  • DSP 빌드 스크립트: HexKL 선택과 DSP 검사.
  • CLI 구현: 위치 인자와 프롬프트 처리.
  • Quick.AI 빌드 문서: 기록된 환경과 빌드 절차.
  • CLI 및 C API 테스트 문서: 실행 명령과 수명 주기 테스트.
  • 앱 사용법 및 알려진 제약: 조작 방법, 권한, 오류 유형.
