Hexagon NPU에서 Gemma4-MoE 실행하기

이 가이드는 Linux PC와 Android 휴대전화에서 도구를 준비하고, 명령줄 또는 Quick.AI Android 앱으로 Gemma4 26B-A4B의 첫 응답을 생성하는 과정을 설명합니다. 툴체인 설치, nntrainer 빌드, 런타임 설치, 모델 팩 복사, 실제 NPU 실행 여부 확인까지 순서대로 진행합니다.

기준 소스: PR #4480의 커밋 67d2903a279a3f5604074f001bbf8f814dfb9f82. 2026-11-05에 내용을 검토했습니다. 아래 명령은 SDK와 HexKL 6.4.0.1 조합, 업데이트된 Metrics 벤치마크, 2,304개 위치의 Gemma4 채팅 프리셋이 포함된 이 리비전을 기준으로 합니다. 화면 캡처와 벤치마크의 날짜는 아래에 따로 기록했습니다. 다른 체크아웃에서는 명령이나 기능이 달라질 수 있습니다.

별도로 제공되는 실행 가능한 Gemma4 HTP 모델 팩이 필요합니다. 이 저장소와 APK에는 가중치가 포함되어 있지 않습니다. 이 PR에는 제공용 모델 팩의 공개 다운로드 URL이 안내되어 있지 않습니다. 추론을 시작하기 전에 모델 제공자로부터 팩과 그에 맞는 설정을 받아야 합니다. 일반 Hugging Face 체크포인트를 다운로드하는 것만으로 이 단계를 대체할 수는 없습니다.

bash 코드 블록은 adb로 시작하는 명령을 포함해 모두 Linux PC의 Bash에서 실행합니다. sh 블록은 휴대전화의 adb shell 안에서 실행합니다. 예제 경로는 실제 절대 경로로 바꾸세요. 내보낸 환경 변수가 유지되도록 같은 호스트 터미널에서 계속 진행하세요. 오류가 발생하면 해결한 다음 단계로 넘어가세요. 명령, 옵션, 로그, 앱의 UI 이름은 실제 화면과 대조할 수 있도록 원문을 유지합니다.
