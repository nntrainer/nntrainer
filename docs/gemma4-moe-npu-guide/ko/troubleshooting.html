문서/참고 자료/문제 해결

10. 문제 해결

증상 확인 및 해결 방법
adb에서 unauthorized 표시 휴대전화 잠금을 해제하고 USB 디버깅을 승인합니다. 요청이 나타나지 않으면 케이블을 다시 연결하세요.
Ubuntu에서 adb 권한 오류 USB 규칙용 android-sdk-platform-tools-common을 설치하고 기기를 다시 연결합니다. 필요하면 배포판 안내에 따라 plugdev 그룹을 설정하세요.
more than one device/emulator 각 호스트 터미널에서 대상 기기의 시리얼을 ANDROID_SERIAL로 지정합니다.
--htp requires ... 현재 터미널에서 Hexagon SDK 환경을 불러오고 HexKL/Android 변수를 다시 내보냅니다.
libsdkl.so 또는 libhexkl_micro.a 누락 압축 해제 루트와 6.4.0.1, armv8_android26, hexagon_toolv19_v81 하위 디렉터리를 확인합니다. ZIP이나 상위 디렉터리를 지정하지 마세요.
빌드가 HEX_ARCH를 거부 이 Android 경로는 v81이 필요합니다. 다른 값을 설정한다고 다른 기기를 지원하게 되지는 않습니다.
cargo 또는 Android 토크나이저 아카이브 누락 Rust/Cargo가 PATH에 있고 aarch64-linux-android 타깃이 설치되었는지, ANDROID_NDK가 올바른지 확인한 뒤 다시 빌드합니다.
Gradle이 SDK나 라이선스를 찾지 못함 ANDROID_HOME, 플랫폼 36/build-tools/CMake 설치 상태, sdkmanager --licenses를 확인합니다. 오래된 local.properties가 다른 SDK를 가리킬 수 있습니다.
Gradle의 Java 또는 NDK 불일치 java -version, JAVA_HOME, ANDROID_NDK/source.properties를 확인합니다. -PnntrainerNdkPath를 전달하는 표준 빌드 스크립트를 사용하세요.
--htp and --qnn select separate native variants 이전 스크립트의 오류입니다. 기준 리비전은 --qnn --htp를 지원하며, 이 가이드에는 --htp만 필요합니다. 체크아웃을 확인하세요.
CANNOT LINK EXECUTABLE / .so 누락 run_causallm.sh를 사용하고 전체 런타임을 다시 배포한 뒤 LD_LIBRARY_PATH를 확인합니다.
CLI가 매우 느림 / DSP 열기 실패 / CPU fallback ADSP_LIBRARY_PATH, v81 skel, vendor FastRPC와 기기 호환성을 확인합니다. 터미널 출력과 logcat을 모두 살펴보세요.
HTP_GRAPH_E_UNSUPPORTED ARM과 DSP 산출물이 서로 다른 빌드에서 왔을 수 있습니다. 같은 빌드의 전체 세트를 다시 빌드하고 배포하세요.
API가 ADSP_LIBRARY_PATH 충돌 보고 최신 run_test.sh를 빌드·설치하세요. 경로 끝에 콜론이 없어야 하며 QUICKAI_NATIVE_LIB_DIR와 같아야 합니다.
두 번째 생성에서 rows [...] do not fit a KV cache 오류 새 프롬프트마다 attention 캐시 기준 위치를 초기화하는 수정이 반영되었습니다. 같은 빌드의 런타임 라이브러리와 DSP 이미지를 다시 배포하고 7단계 수명 주기 명령으로 반복 생성을 확인하세요.
앱에서 Unload failed 표시 네이티브 작업 프로세스가 정상적으로 해제되지 않은 상태입니다. 표시된 오류를 해결하고 Unload를 다시 시도한 뒤 다른 모델을 로드하세요.
앱이 모델 팩을 찾지 못함 Base path, 정확한 디렉터리 이름, 모든 파일 접근 권한, adb push 후 디렉터리가 추가 중첩되었는지 확인합니다.
앱이 설정을 찾았지만 로드 실패 가중치 파일 이름과 크기, 최상위 텍스트 모델 설정, 참조된 보조 파일, 제공자의 체크섬을 확인합니다. 설정과 가중치는 같은 팩의 것을 사용하세요.
INSTALL_FAILED_UPDATE_INCOMPATIBLE 이미 설치된 APK의 서명 키가 다릅니다. 가능한 한 같은 키를 사용하세요. 교체해야 한다면 필요한 앱 데이터를 백업한 뒤 기존 앱을 삭제하고 새 APK를 설치합니다. 삭제 시 앱의 내부 데이터도 지워집니다.
앱이 16 KB 메모리 페이지 경고 표시 기준 기기는 4 KB 페이지를 사용합니다. 경고가 있다고 16 KB 기기와 호환되는 것은 아닙니다. getconf PAGE_SIZE가 4096인지 확인하세요.
답변이 thought 채널 마커로 시작 logcat에서 Chat template apply failed를 확인하고 제공자/프리셋의 맞는 채팅 템플릿을 복원합니다. 가중치 형식 설정을 다른 프리셋으로 덮어쓰지 마세요.
답변이 멈추지 않거나 항상 같은 길이 벤치마크용 팩일 수 있습니다. EOS 종료가 설정된 채팅 프리셋을 요청하세요. 팔레트 프리셋의 EOS ID는 [1, 106, 50]이고 bad_word_ids는 비어 있습니다.
이전 메시지나 긴 프롬프트의 끝을 무시 HTP 앱의 각 호출은 독립적이며 긴 프롬프트는 잘릴 수 있습니다. 짧고 독립적인 질문으로 확인하세요.
로드 또는 생성 중 앱 종료 제공자의 설정을 기준으로 컨텍스트/캐시 사용을 줄이고 메모리를 많이 쓰는 다른 앱을 종료합니다. CLI와 앱 추론을 동시에 시작하지 마세요.

문제를 보고할 때 기준 소스 해시, SDK/HexKL/NDK 버전, 기기 모델/OS/페이지 크기, 실패한 명령, 팩 형식, 관련 빌드 또는 실행 로그를 포함하세요. 로그에는 프롬프트와 답변이 들어갈 수 있으므로 공유 전에 확인하세요.
