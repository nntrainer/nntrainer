8. Quick.AI 앱 빌드 및 설치

아래 화면은 2026년 11월 4일 Galaxy S26 Ultra(SM-S948N / SM-S948U, Android 16, 4 KB 페이지)에 설치된 Quick.AI 2.0에서 직접 캡처했습니다. 화면의 버튼 이름은 앱에 표시되는 영어를 그대로 사용합니다. 이미지를 누르면 원본 크기로 볼 수 있습니다.

APK 빌드 및 설치

호스트 PC에서 앞서 설정한 환경과 같은 소스 리비전을 사용합니다.

cd "$NNTR_ROOT/Applications/CausalLM"
set -o pipefail
./build_android.sh --htp --cache --app 2>&1 | tee "$NNTR_ROOT/gemma4-app-build.log"

네이티브 라이브러리를 준비하고 라이브러리 AAR 및 예제 APK를 빌드한 뒤 verify_native_package.py를 실행합니다. 이 검사는 필수 라이브러리, 변경되지 않은 v81 DSP 이미지, 네이티브 라이브러리 의존성을 확인합니다. HTP 패키지에 불필요한 QNN 라이브러리나 vendor의 libcdsprpc.so가 들어 있어도 실패합니다.

산출물 NNTR_ROOT 기준 위치
앱 개발자용 AAR Applications/CausalLM/Android/QuickDotAI/build/outputs/aar/QuickDotAI-debug.aar
설치 가능한 APK Applications/CausalLM/Android/QuickDotAIAPP/build/outputs/apk/debug/QuickDotAIAPP-debug.apk
네이티브 패키지 검증 보고서 APK 경로 뒤에 .native-manifest.json이 붙은 파일

휴대전화에 설치하는 것은 APK입니다. AAR은 다른 앱을 빌드할 때 사용하는 라이브러리이므로 adb install로 설치할 수 없습니다.

호스트 PC에서 완성된 APK를 설치합니다.

cd "$NNTR_ROOT"
adb install -r -t Applications/CausalLM/Android/QuickDotAIAPP/build/outputs/apk/debug/QuickDotAIAPP-debug.apk
adb shell appops set com.example.quickdotaiapp MANAGE_EXTERNAL_STORAGE allow
adb shell pm path com.example.quickdotaiapp

adb install이 Success로 끝나고, pm path가 설치된 APK 위치를 출력해야 합니다. 권한 설정 명령은 /sdcard의 모델 팩을 읽을 수 있게 합니다. 대신 앱이 여는 Android 권한 화면에서 **모든 파일 접근(All files access)**을 허용하거나, 설정 → 앱 → 특별한 접근 → 모든 파일 접근 → Quick.AI에서 허용해도 됩니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.

빌드와 설치를 따로 실행하는 대신 ./build_android.sh --htp --cache --app --install을 사용하면 AAR/APK 빌드, APK 설치, CLI 런타임 배포를 함께 수행합니다. 어느 방법도 모델 가중치는 복사하지 않으므로 6단계를 별도로 완료하세요.

모델 로드 및 메시지 보내기

아래 순서대로 모델 선택 → 로드 완료 확인 → 메시지 전송을 진행합니다. 모델 선택 화면은 기본 경로를 사용합니다. 로드·대화·Metrics 캡처에서는 다른 기기에 준비되어 있던 TL2 팩을 사용했으며 상위 경로는 /sdcard/Download/aistudio-mobile/models_1022입니다. 6단계대로 모델을 복사했다면 아래 표의 기본 경로인 /sdcard/Download/aistudio-mobile/models를 사용하세요.

1. Gemma4 NPU와 모델 경로 선택

상단 바 아래의 모델 선택 칩을 눌러 Model 화면을 엽니다.

화면 항목 선택하거나 확인할 값
FAMILY gemma4-26b-a4b
RUNTIME Quick.AI
BACKEND NPU
MODEL VARIANT 이 가이드에서는 Gemma4 26B A4B MoE (HTP). 선택한 family/runtime/backend에 여러 팩이 있을 때 표시됩니다.
BASE PATH /sdcard/Download/aistudio-mobile/models — gemma4-26b-a4b-htp-w4a32 폴더가 들어 있는 상위 디렉터리
설정 파일 상태 gemma4-26b-a4b-htp-w4a32/nntr_config.json found
모델 정보 칩 HTP · W4A32 · Gemma4 26B A4B MoE (HTP)

found는 설정 파일이 있다는 뜻일 뿐입니다. 가중치나 보조 파일이 없으면 로드가 실패할 수 있습니다. 모델 목록에 Gemma4 NPU가 없으면 설치한 APK가 --htp 빌드의 산출물인지 확인하세요.

2. 모델 로드 완료 확인

Load model을 누르고 기다립니다. Model 화면의 상태가 Loaded로 바뀌면 오른쪽 위 ×를 눌러 닫으세요. 채팅 화면의 상태 줄에 Loaded gemma4-26b-a4b-htp ..., 본문에 Model loaded · start a conversation이 보이면 질문을 입력할 수 있습니다. 로드 시간은 팩과 기기 상태에 따라 달라집니다.

Load failed가 표시되면 질문을 보내기 전에 오류를 해결하세요. 먼저 BASE PATH와 권한을 확인하고, found인데도 실패하면 설치한 앱이 지원하는 팩인지와 필요한 파일이 모두 있는지 확인합니다.

3. 질문 보내기와 생성 중지

하단 Type a message… 입력창에 Explain neural networks in two sentences.를 입력한 뒤 오른쪽 Send 화살표를 누릅니다. 답변이 순차적으로 표시되고 완료되면 상태 줄이 **Done.**으로 바뀝니다. 키보드가 답변을 가리면 Android의 뒤로 가기로 키보드를 닫으세요.

생성 중에는 보내기 버튼이 Stop으로 바뀝니다. 중지하면 해당 응답에 stopped가 표시됩니다. 상단 휴지통의 Clear conversation은 화면의 대화를 지우는 기능이며, 모델을 해제하려면 모델 메뉴의 Unload를 사용합니다.

이 리비전의 HTP 앱은 가장 최근 사용자 메시지만 전달합니다. 이전 말풍선은 이 모델의 대화 기억으로 사용되지 않습니다. 처음에는 짧은 프롬프트를 사용하세요. 설정된 컨텍스트를 초과하는 프롬프트는 오류 없이 잘릴 수 있습니다. 팔레트 채팅 프리셋은 1,280개 위치를 사용하지만 제공받은 TL2 팩은 제한이 다를 수 있습니다. 컨텍스트를 늘리면 RAM 사용량이 크게 증가할 수 있습니다. 이 Gemma4 HTP 팩은 텍스트 전용이며 앱에 다른 모델용 이미지 기능이 있어도 이 경로가 멀티모달로 바뀌지는 않습니다.

4. Metrics 확인 및 모델 해제

하단 Metrics 탭을 열면 마지막 실행 결과가 표시됩니다. 숫자는 캡처한 한 번의 실행 예시이며, 팩·프롬프트·기기 상태에 따라 달라집니다.

항목 읽는 방법
TIME TO FIRST TOKEN 질문을 보낸 뒤 앱이 첫 토큰을 받기까지의 시간입니다.
STEADY DECODE 두 번째부터 마지막 토큰까지, 토큰당 생성 시간의 중앙값입니다. 단위는 ms/tok입니다.
GENERATION / PREFILL 각각 출력 생성과 입력 처리의 속도, 토큰 수, 소요 시간을 보여 줍니다.
PEAK MEMORY 앱이 보고한 최대 메모리 사용량입니다. 가중치 파일의 저장 공간과는 다른 값입니다.
Recent runs / Raw output of the last run 최근 실행 기록과 마지막 응답의 원시 텍스트입니다. 원시 출력은 펼쳐서 확인합니다.

최신 라이브러리는 <turn|> 같은 대화 종료 마커를 스트림에서 제거합니다. 채팅 말풍선과 Metrics의 원시 출력에는 표시되지 않으며, 종료 토큰은 네이티브 토큰 트레이스에서 확인합니다(Gemma4 ID 106).

사용을 마치거나 CLI를 다시 실행하려면 상단 모델 선택 칩 → Unload를 누릅니다. 다시 시작할 때는 Load model, 이미 로드한 모델을 새로 열 때는 Reload model을 사용합니다. 최신 앱은 네이티브 추론을 별도 작업 프로세스에서 실행하고, 해당 프로세스가 종료된 뒤 다음 모델을 로드합니다. NPU 모델은 한 번에 하나만 로드하세요.
